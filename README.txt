국방예산 웹 대시보드

실행: index.html 파일을 더블 클릭해 웹 브라우저에서 열어주세요.
설치나 인터넷 연결 없이 실행됩니다.

기능
- 부문 및 회계구분 연동 필터, 필터 초기화
- 예산 비교, 부문 구성비, 회계별 재원, 상위 프로그램, 증감 기여도,
  규모·성장률 산점도, 구분별 예산 지도, 변화 분포의 8개 시각화
- 그래프 위에 마우스를 올리거나 키보드로 선택하면 상세 금액 표시
- 프로그램 상세 검색, 금액·증감·증감률 정렬
- 필터 및 검색 결과 CSV 다운로드
- 모바일 화면 대응

데이터: 상위 폴더의 프로그램별_재원.xlsx에서 추출한 32개 항목.
단위: 억 원. 증감률은 엑셀 숫자값을 기준으로 직접 계산합니다.
원본 보고서에 반올림된 금액과 비율은 일부 차이가 날 수 있습니다.
비중 그래프는 양수 재원만 포함하며, 순재원 합계는 차감 항목을 포함합니다.
엑셀 변경을 자동 감지하지 않으며, data.js는 작성 시점의 스냅샷입니다.

파일 구성: index.html / style.css / app.js / data.js / README.txt
